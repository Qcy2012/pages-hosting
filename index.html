快速开始

只需要三步即可完成静态网站部署：

  1. 注册账号并创建新的托管项目
  2. 上传你的静态文件（HTML/CSS/JS/图片等资源）
  3. 等待几秒即可获得专属访问域名，全球可访问
提示：单文件大小不超过100MB，总项目大小不超过1GB即可免费使用。

Git 自动部署

绑定你的GitHub/GitEE仓库，每次推送代码自动触发部署：

# 1. 在项目设置中关联你的Git仓库
# 2. 选择需要部署的分支（通常是main或gh-pages）
# 3. 指定构建命令和输出目录（如npm run build → dist/）
# 4. 完成配置后，每次git push自动部署更新

自定义域名配置

支持绑定你自己的域名，自动配置HTTPS证书：

  • 进入项目设置 → 域名管理 → 添加自定义域名
  • 在你的域名服务商处添加CNAME记录指向我们提供的接入域名
  • 等待DNS生效后，系统将自动申请并配置SSL证书

常见问题

Q：支持哪些类型的网站？
A：支持所有纯静态网站，包括HTML/CSS/JS编写的站点、Vue/React等框架打包后的产物，不支持PHP/Node.js等需要服务器运行的动态项目。

Q：部署后的网站有流量限制吗？
A：免费版每月提供100GB流量，足够个人博客、小型作品集使用。

Q：部署后可以回滚到历史版本吗？
A：支持，系统会保留最近10次部署记录，一键即可回滚到任意历史版本。
